🛠 Migración de Agencias a Firestore

Este script migra el organigrama de agencias hardcoded al documento shared/agencias en Firestore. Es de un solo uso.

⚠️ Importante:
  • Este script sobrescribe el documento shared/agencias completo.
  • Si ya existen datos en Firestore, se reemplazarán con los del JSON.
  • Solo el admin (it@heroinsuranceusa.com) puede ejecutarlo (regla Firestore).
  • Después de ejecutar exitosamente, borra este archivo del repo.
