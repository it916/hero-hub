🛠 Migración de Planes a las Agencias

Este script agrega el campo planes a cada agencia en shared/agencias, según los datos que tú indicaste.

⚠️ Importante:
  • Este script solo modifica el campo planes de cada agencia. No borra ni cambia nada más.
  • El matching de nombre es insensible a mayúsculas (VITANOVA = Vitanova).
  • Las agencias que no tengan info de planes en la captura recibirán planes: [] (array vacío).
  • Solo el admin (it@heroinsuranceusa.com) puede ejecutarlo.
  • Después de ejecutar exitosamente, borra este archivo del repo.
